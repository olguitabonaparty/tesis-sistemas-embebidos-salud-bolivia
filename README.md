# tesis-sistemas-embebidos-salud-bolivia

# Diseño y Optimización de Sistemas Embebidos para Aplicaciones en el Área de Salud en Bolivia

## Descripción
Proyecto de investigación desarrollado como trabajo de grado de Ingeniería Electrónica y Telecomunicaciones.

## Objetivo
Diseñar e implementar un sistema embebido basado en ESP32 para el monitoreo de variables biomédicas y ambientales en entornos hospitalarios.

## Tecnologías Utilizadas
- ESP32
- MAX30102
- LM35
- DHT22
- LDR
- PCB Design
- Arduino IDE
- IoT

## Funcionalidades
- Monitoreo de frecuencia cardíaca y saturación de oxígeno.
- Medición de temperatura corporal.
- Medición de temperatura y humedad ambiental.
- Monitoreo de iluminación en habitaciones hospitalarias.
- Visualización de datos en pantalla LCD.

Diseño de la PCB del Prototipo de CCH

Ensamblaje de los componentes a la placa PCB del Prototipo de CCH
El prototipo desarrollado integra un sistema avanzado de monitoreo y control en
cabeceras de camas hospitalarias. Este sistema permite la supervisión en tiempo real de
parámetros críticos para la salud del paciente, como la temperatura ambiental, la
humedad, la temperatura corporal, la frecuencia cardíaca y los niveles de oxigenación.

## Interfaz de Usuario de la CCH
Toda esta información está accesible a través de un servidor local (localhost), garantizando 
la seguridad y la privacidad de los datos del paciente. Esta disposición de la interfaz facilita 
una monitorización exhaustiva y personalizada, mejorando la calidad del cuidado 
proporcionado.
